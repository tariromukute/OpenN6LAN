# Setup wireshare with edgeshark on docker

## Installation

**Install wireshark**

```bash
sudo apt update

sudo apt install wireshark

# 
sudo chmod +x /usr/bin/dumpcap
```

**Install Containershark Extcap Plugin for Wireshark**

Follow the instructions on the [repo](https://github.com/siemens/cshargextcap?tab=readme-ov-file#installation)
